# Privacy

The decision evaluators (`evaluate`, `evaluate_json_table`, `evaluate_decision`) perform no external requests, execute no business action, and read/write no business files. Data, rules and typed snapshots are processed in the Dify plugin process. They use no LLM, telemetry, arbitrary code execution or evaluation cache.

`query_local` returns only fixed SYNTHETIC fixtures. `execute_json_plan` is a SYNTHETIC / ADVISORY_ONLY local adapter and uses those fixtures, not production services. `execute_query` fails closed in the default SDK installation because no trusted deployment is configured. A separately integrated trusted host may register a read-only query capability, online authorization callback and fixed transport. Only that explicitly configured host path can send bound query inputs to registered endpoints. Inputs cannot supply arbitrary URLs, headers, credentials, modules or code. The optional fixed transport has no saved credentials and refuses DNS, ambient proxies and redirects; production connections are not bundled or validated.

The Endpoint serves three fixed viewer assets. Imported JSON is parsed in browser memory: it is not uploaded, executed or persisted by the viewer. No analytics or external viewer requests are configured. The separate offline HTML is self-contained.

Dify, its plugin SDK and any separately integrated host may keep invocation inputs, outputs, errors, workflow snapshots and normal operational metadata under their own policies. This package cannot disable or guarantee the absence of platform logging. Error messages use fixed descriptions and structural paths rather than input values. Rule/variable identifiers, selected business output, provenance and intended action parameters appear in results as required by their contracts.

Dependency installation may require access to your approved Python package registry. Runtime transport between Dify and the plugin is provided by the official SDK. Only independently designed synthetic rules and data are included; no company source code, production rules or credentials are bundled. Review signing/trust policy, resource limits, workflow access and host connections before installation.
