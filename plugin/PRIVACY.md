# Privacy
This plugin sends the saved DMN XML, decision ID and facts JSON only to the private engine origin configured by the workspace administrator. The engine bearer token is sent only in the Authorization header. Redirects and process-wide HTTP proxies are disabled. Neither this plugin nor the supplied engine intentionally logs or persists model/fact bodies. Dify itself can retain workflow definitions, inputs, outputs, execution traces and encrypted provider credentials according to your deployment's settings. Administrators must review those retention settings and restrict who can edit provider endpoints or DMN models. No telemetry, public DMN service or LLM call is used by this plugin.
